# Norex Poster Tool

Open `index.html` to use the combined portal with all three posters.

Use `Norex All Posters Portal - Portable.html` for one portal with all three posters.

Use `Norex Poster Tool - Portable.html` for daily updates.

Use `Norex Toman Poster Tool - Portable.html` for the single buy/sell Toman poster.

## Daily Use

Send `Norex Poster Tool - Portable.html` to the iPhone and open it from the Files app.

The date and days-to-go number fill automatically. Change the days-to-go number or buy/sell rates and tap `Apply & Download`. On iPhone, long-press the poster image and save it.

The tool is portable. You can move `Norex Poster Tool - Portable.html` to another laptop and it will still work because the poster template is embedded inside the file.

## GitHub Pages

In the GitHub repo, go to `Settings` > `Pages`.

Set `Source` to `Deploy from a branch`.

Set `Branch` to `main` and folder to `/ (root)`, then save.

After GitHub finishes deploying, the site will be available at:

`https://yasaminasadian.github.io/Norex/`
